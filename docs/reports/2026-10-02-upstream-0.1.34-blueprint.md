# Upstream Strata v0.1.34: blueprint, compared with the fork, and the merge checkpoint (2026-10-02, #100)

This document has three parts:

- **Part A** describes upstream as released (`Niko1221/Strata` `v0.1.34` = `1678de3`), area by area.
- **Part B** sets each area beside the fork (`xenodeve/Strata-xeno` `main` = `1c2b520`; the fork's own map is `docs/BLUEPRINT.md`) and records how the merge on `xeno/exp-upstream-0.1.34` reconciles them.
- **Part C** is the checkpoint of the unfinished merge.

**What is unverified.** The merge resolution is NOT built and NOT tested yet. Part B's "merge" column records what the resolver agents wrote and the adversarial reviewers checked by reading the code. It is a description of the code as resolved, not a measured result. Part A is drawn from upstream's release notes (v0.1.31-v0.1.34), its source at `1678de3` and the resolver records. Speed figures are upstream's own claims and are marked **VENDOR**.

Common ancestor: `v0.1.30` (`30ec18e`). Since then upstream has 189 commits and the fork 255. The upstream diff touches 246 files (+62,409 / -1,642). Most of it is community benchmark data (`bench/results/`, about 30 %), docs, `setup.py`/`tools/` and AMD/HIP; the engine source is a smaller share.

## Part A - upstream v0.1.34, area by area

### A1. Models and expert formats
- **Native expert formats.** The formats now include **Q4_K, Q5_K, Q5_1 and Q8_0**, beside the i-quants (IQ1_M, IQ2_XS, IQ3_XXS, IQ3_S) and Q2_0.
  - `is_iq` covers types 7, 8, 11, 12, 13 and 30; `native_expert_supported(gu, d, n_embd, n_ff)` checks the gate/up and down type *pair*.
  - Upstream says the GPU dequantizers match llama.cpp bit for bit, and the CPU dot products match ggml within float rounding (VENDOR).
- **Unsloth UD-Q4_K_XL (experimental)** is a 4-file, 111 GB model with 72 GiB of experts. Setup supports it (`--family unsloth --model UD-Q4_K_XL`), with per-file size and SHA-256 checks. See `docs/UNSLOTH_Q4.md`.
- **Multi-file GGUF experts read in place.**
  - `include/strata/artifact/gguf_split.hpp` handles split GGUFs.
  - `native_experts.txt` is **v4**: `kExpertLayoutVersion = 4`. Its `gguf_file` column is **per role**, since a shard boundary can fall inside a layer (#255).
  - A missing file is an error.
- `check_experts_gguf` validates every role tensor against the pack before any allocation: name, type, shape `[cols, rows, experts]`, bytes per expert, offset, and the end of file.
- Other new pieces:
  - the Cyrillic draft-vocab subset (`data/draft_vocab_cyrillic.bin`);
  - `tools/embd_bf16_pack.py`;
  - `tools/ple_fp8_pack.py` (FP8 PLE rows, hence `PLE_ROW_BYTES_MAX`);
  - `docs/ORCA_Q4_K_S.md`.

### A2. Process picture
- The process model is unchanged from v0.1.30: `serve/server.py` (Python HTTP server) drives one `strata --serve` engine process over stdin/stdout `GEN`/`T`/`DONE` lines.
- An optional vision encoder runs as its own process.
- New pieces:
  - **`tools/strata_mcp.py`**: an MCP server that lets an AI assistant install, start, check and stop Strata (#133, `docs/MCP_SERVER.md`);
  - `serve/structured.py` (structured output);
  - `serve/web/monitor.html` / `monitor.js` (the Monitor);
  - the lazy engine start (`StrataEngine(..., lazy=)`).

### A3. File responsibilities (what moved)
- **`src/program/generate.cpp`:**
  - new flags (see A7);
  - the pin cap rewrite (#243 / #253: `arena_pin_cap_gib`, an 8 GiB cap only under WDDM, `STRATA_ARENA_PIN_GIB`);
  - `ExpertPool(..., PoolAffinity)` (#272);
  - the per-layer cache admission (#369);
  - the prompt-path retry loop `init_prompt_paths` with chunk step-down (#253);
  - the split refill on all cards at once (#340);
  - async commit (`Verifier::set_commit_async(!multi_gpu)`).
- **`src/core/expert_source.cpp`:** `check_experts_gguf`; per-role readers; the `FileExpertSource` GGUF-in-place mode with transient `blob()` buffers (`kStageAge` = 3 layer changes); `prefetch()` (the routing prefetch one layer ahead); `copy_blob`.
- **`src/kernels/cuda/iq_kernels.cu`:** decode-once multi-expert kernels `native_gu_multi_kernel` / `native_down_multi_kernel` (`Split<T>`, `GRP_NC`), with the type lists in the macros `STRATA_GU_FMTS` / `STRATA_D_FMTS`. Upstream states they are bitwise identical (#241, #242).
- **`src/kernels/cuda/s2_expert_grouped.cu`:** rewritten per-hit and grouped S2 kernels (said to be bitwise identical). They fall back to the old kernels when activations, scratch, arena or slot are misaligned.
- **`src/prefill/*`:**
  - BF16X2 hyper-connection kernels (a trailing `*_lo` parameter on `gr_norm` / `gr_norm_rs` / `gr_mix_r` / `gr_write_norm_rs` / `gr_silu` / `gr_mix` / `to_bf16`, default `nullptr`);
  - `Prefill::reset()` (frees everything);
  - `MoeMmq::fits()` and the FP16 fallback when MMQ has no tile that fits (`J_best = 0`, #420);
  - the FP16 SwiGLU now saturates at +/-65504 instead of overflowing (a numerics change for huge activations only).
- **`src/core/verify.cpp`:** `set_commit_async` and `window_logprobs`. With async commit, `commit()` returns after the graph launch; `wait_commit()` is the sync point, and `STRATA_COMMIT_SYNC=1` forces the sync. Upstream measured +5.6 % decode with the same tokens (VENDOR).
- **`src/kernels/cpu/pool.cpp`:** `detect_cpu_topology` (hybrid P/E detection on Windows and Linux) and `PoolAffinity` {All, Auto, PCores}.
- **`src/kernels/ngram.cpp`:** FP8 PLE rows (`PLE_ROW_BYTES_MAX`, `decode()`).
- **`src/core/device.cu`, `device_main.cpp`:** `device_code_error()`; `kMinCc` / `kNeed` (sm_75 floor in release builds); `--list-devices` for setup.
- **`src/kernels/cpu/expert_layout.cpp`:** `cpu_avx2_ok()`, `cpu_name()`, and the `kq_avx2` CPU K-quant dot products.

### A4. The life of a request (server)
- **The late-request status fix (#266):** a slot, then `try` / `except GeneratorExit` / `finally` settle. An outer `finally` unlinks the embeddings.
- **The CJK tokenise speedup (#268):** a long unbroken run of CJK text (or a URL) took seconds.
- **#430/#431:** a client hang-up cancels within about one second. Before, a non-streamed request ran to `max_tokens` and a streamed one read its whole prompt.
- **#208/#332:** an OpenAI request that arrives while the engine (re)loads waits in the queue.
- **Errors:**
  - `EngineStuck`;
  - a 400 for a template-refused request (#365);
  - CORS origins and trusted origins;
  - `/health` and `/api/health` both answer, with `service: strata`.
- **The reasoning budget (#123):** counts reasoning tokens and cuts at a clean point with `REASONING_WRAP_UP`.
- **Aliases and counting:** `model_for(req)` (#297); `count_tokens` dispatches on the query-stripped path.

### A5. Memory hierarchy and decode dispatch
- **VRAM expert cache:**
  - `--expert-cache N` slots;
  - `--expert-cache-per-layer` with per-layer admission (#369: the boot fill skips a pair whose own layer is full instead of stopping);
  - R4 admission;
  - `--expert-cache-remote` stripe/layer placement on CUDA1..3.
- **RAM: three modes, all static:**
  - `--resident-experts` / `--resident-cpu-experts`: page-locked when the driver allows, with 4 GiB of headroom;
  - **`--resident-budget-gib N` (CS-T):** the N GiB of experts that the profile ranks hottest and that the GPU cache does not hold are copied into RAM; the rest are read **in place from the GGUF files through mmap and the OS file cache**, prefetched one layer ahead from the router's prediction. Upstream measured about 7-8.5 tok/s for UD-Q4 on an RTX 5070 with 64 GB and a 40 GiB budget (VENDOR);
  - `--mmap-experts` (low RAM; 0.1.31 reads a pack's experts straight from the GGUF when there is no `experts.bin`).
- **Layer split across GPUs:**
  - prompt loans of each card's expert cache, refilled after every request;
  - 0.1.32 refills all cards at once (`refill_issue` / `refill_wait`, `STRATA_REFILL_SERIAL`), uses a smaller ring on a split (`STRATA_SPLIT_SMALL_OWN` / `MAX`), and lets a card with free VRAM keep its own prompt buffers (`STRATA_SPLIT_OWN`, `STRATA_SPLIT_OWN_BUFFERS`);
  - `--split-skip-if-fits`.
- **Decode:** async commit, as in A3.

### A6. KV cache and checkpoints
- **The conversation cache (#342):** `drop_superseded` removes parked conversations whose deepest checkpoint the outgoing chain still holds.
- `--kv-streaming on|off|auto` comes through setup (0.1.33).
- From 64K context, the KV cache can move to RAM in the low-RAM mode.
