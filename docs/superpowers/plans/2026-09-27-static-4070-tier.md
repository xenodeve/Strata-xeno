# Static 4070 SUPER Expert Tier Implementation Plan

> For agentic workers: execute tasks in order with red/green tests and a reviewable commit per slice. The AFK authorization permits local branch execution; no PR or main merge is authorized.

**Goal:** Compute a static, profile-ranked subset of native Q2_0 experts on the display RTX 4070 SUPER while preserving the accepted greedy baseline and at least 2560 MiB of measured free display VRAM.

**Architecture:** Keep the existing 5060 Ti graph and cache. Add a secondary-device arena and static residency table. In native verify-window host dispatch, use published activations and router IDs to route each distinct remaining expert to device 1 or the CPU, then join partials before the existing primary-device combine.

**Tech stack:** C++20, CUDA 13.3, MSVC 2022, CMake/CTest, Python token-parity harness.

**Spec:** `docs/superpowers/specs/2026-09-27-static-4070-tier-design.md`.

## Global constraints

- `CUDA_VISIBLE_DEVICES=1,0`: 5060 Ti is CUDA 0, display 4070 SUPER is CUDA 1. Never infer identity from ordinal alone; inspect device name/SM.
- Keep at least 2560 MiB actually free on the 4070 SUPER after allocations are touched and at every measured work boundary. If unavailable, refuse/disable secondary tier. Do not alter the single-GPU path when the tier is off.
- Do not edit `C:\AI`, overwrite ignored user launchers/config, stop unrelated processes, open PR, or merge main.
- Use the accepted Q2_0 `double-exp` baseline (ADR 0001). Count each routed expert once and preserve router-index rows and weights.

## Review focus

- Device ordinal accidentally reversed by visible-device order.
- WDDM allocation reports plenty of free memory before touch, then breaches reserve after touch.
- Secondary result read before the device-1 event completes or after a staging buffer is reused.
- Repeated expert ID across verify tokens gets computed twice or writes the wrong router row.
- A secondary error silently turns an expert into zero output or leaves stale output from a previous layer.
